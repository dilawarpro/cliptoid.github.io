Cliptoid web app

Install Cliptoid on your device

Cliptoid is a browser-based tool that you can add to a compatible device's home screen. There is no separate APK or app-store download required. The website also remains available in your browser if installation is not offered.

Install Cliptoid

Use the button when your browser supports app installation. If no prompt appears, follow the device-specific browser steps below.

Installation steps

Android

  1. Open cliptoid.com in a supported browser such as Chrome.
  2. Choose Install app from the prompt, or open the browser menu and choose Install app or Add to Home screen.
  3. Confirm the prompt to add Cliptoid to your device.

iPhone and iPad

  1. Open cliptoid.com in Safari.
  2. Tap Share, then choose Add to Home Screen.
  3. Confirm the name and tap Add.

Desktop

  1. Open cliptoid.com in a supported desktop browser.
  2. Select the install icon in the address bar, or use the browser menu's Install Cliptoid option.
  3. Confirm to open Cliptoid from your apps or desktop.

Use Cliptoid after installation

  1. Copy the link to a public TikTok post you can access.
  2. Open Cliptoid and paste the link into the downloader.
  3. Review the result and choose an available video, audio, or slideshow option. Captions and hashtags may also be available to copy.

Results depend on the post and browser. Some links or formats may not be available. Installing Cliptoid does not change TikTok access settings or grant permission to reuse a creator's content.
